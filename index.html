HRIS Template Completion Tracker

An automated pipeline that tracks about 29 HR data-collection templates across 9 business units. A scheduled Power Automate flow scans a SharePoint library every day, flags files untouched for more than 7 days as stale, and keeps one row per file in an Excel table. Power BI reads that table for a live completion dashboard.

Two details I'm proud of: rows are updated instead of duplicated on every run, and completion is measured per unit against only the templates that apply to it. The flow never modifies the source files, and it only checks when a file was last touched, not what is inside it.

  • Power Automate
  • SharePoint
  • Excel Online
  • Power BI
